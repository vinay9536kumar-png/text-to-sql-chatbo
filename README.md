# Text-to-SQL Chatbot

A chatbot that lets you ask questions about a database in plain English (or Hindi). It uses the **Google Gemini API** to turn your question into a SQL query, runs the query on a **SQLite** database, and returns the result along with a short answer in simple language.

## Example

```
Sawal: sabse zyada salary kiski hai?

SQL: SELECT name, salary FROM employees ORDER BY salary DESC LIMIT 1

name  | salary
Rohit | 61000

Jawab: Rohit ki salary sabse zyada hai, 61000 rupaye.
```

## How It Works

```
Question -> Gemini (writes SQL) -> Safety check -> SQLite (runs query) -> Gemini (writes short answer)
```

1. The database schema (table and column names) is sent to Gemini along with your question.
2. Gemini returns one SQL query.
3. The program checks that the query is a read-only `SELECT`. Anything that changes data (`INSERT`, `UPDATE`, `DELETE`, `DROP`, and so on) is blocked.
4. The query runs on a read-only connection, so the data cannot be changed.
5. The result is shown as a table, and Gemini writes a one-line answer.

## Features

- Ask questions in English or Hindi
- Shows the generated SQL, so you can check what was run
- Blocks any query that is not a `SELECT`
- Read-only database connection
- Works with a sample company database that is created automatically

## Tech Stack

- **Python 3.12**
- **SQLite** (built into Python, no separate install needed)
- **Google Gemini API** (`google-genai`) for SQL generation and answers
- **python-dotenv** for loading the API key from a `.env` file

## Project Structure

```
create_db.py      # Creates company.db with sample employee and department data
text_to_sql.py    # The chatbot: question -> SQL -> result -> answer
```

## Setup

### 1. Clone the repository

```bash
git clone https://github.com/vinay9536kumar-png/text-to-sql-chatbot.git
cd text-to-sql-chatbot
```

### 2. Create and activate a virtual environment

```bash
py -3.12 -m venv venv
venv\Scripts\activate
```

### 3. Install dependencies

```bash
pip install google-genai python-dotenv
```

### 4. Add your Gemini API key

Create a file named `.env` in the project folder:

```
GEMINI_API_KEY=your_api_key_here
```

You can get a free key from [Google AI Studio](https://aistudio.google.com/). Never commit `.env` to GitHub. It is listed in `.gitignore`.

## Usage

### Step 1: Create the sample database

```bash
python create_db.py
```

This creates `company.db` with two tables:

- `departments`: `dept_name`, `location`
- `employees`: `id`, `name`, `department`, `salary`, `joining_date`

### Step 2: Start asking questions

```bash
python text_to_sql.py
```

At the `Sawal:` prompt, type a question. Type `exit` to quit.

Questions you can try:

- IT department mein kitne employees hain?
- Sales wale employees ka average salary kya hai?
- Pune mein kaun se department hain?
- 2023 ke baad kitne employees join hue?

## Notes

- Gemini sometimes returns a 503 "high demand" error. Wait a minute and try again, or change `MODEL` in `text_to_sql.py` to another Flash model.
- The answer is generated by an LLM, so always check the SQL line if a result looks wrong.
